Demo

Watch the trained attribute model decide an image, one attribute at a time, or switch to Training to watch how it learned to. This page is for showing people how it works: it changes nothing and saves nothing.

Space pauses, N is next image, T switches view, F is full screen

Go to Train model

What's real: the picture, the strip of numbers the image model turned it into, the lines (how hard each part of that strip pushes toward or away from an answer), the percentages, the answer picked, and what the annotator said. Held-out images come first, so the model has never trained on what you're watching it decide. What's simplified: the image model in the middle has tens of millions of connections, so its neurons are a drawing, and each cell of the strip stands for a run of the real numbers.

What's real: this is the model's training, run again the same way: the same labelled images, the same starting lines, the same number of steps. Each attribute's lines start out random and close to nothing and are nudged, step by step, to shrink the error on the training images. The lines, the percentages for this image, the error and the share right on held-out images are the real values at each step, and the run ends on the model in use (the stage says so if the training set has changed since). The image model is frozen: training never touches it. What's simplified: early steps are stretched out and later ones fast-forwarded, because most of the change happens early; between the steps that were kept, the picture is blended smoothly; and only the lines that end up strongest are drawn.
