Train model

Trains the first-pass attribute model on what annotators have recorded, then pre-fills its guesses, in four steps. Each step's latest result stays on this page, and your paths are remembered for next time. Everything it writes goes into the training/ folder. To compare image-screening models (how many satellites, and whether one is recognizable), label a check set.

1 Training set

Old-tool CSVs (one per annotator) plus the folders their images were moved to. Rows are matched to images by file name. Unknown, unusable and column-shifted answers are left out. 


    

  


  

    
2 Embed

    

      Runs every training-set image (and every active scraped image) through a frozen pretrained image model.
      Images already embedded are skipped. The first run downloads the model, which needs HF_TOKEN
      for DINOv3.
    

    

      
      

    

    
    
Images embedded 0 / 0

    

    

  


  

    
3 Train and score

    

      Trains one small classifier per attribute and scores it on satellite families it never saw.
      Baseline always gives the most common answer, so a useful attribute clearly beats it.
      Pre-fill is how many fields would get a guess at that confidence, and how often those
      guesses are right.
    

    

      
    

    
    

    

  


  

    
4 Pre-fill guesses

    

      Works out the trained model's guesses for every image waiting for annotation, ahead of time. With
      Auto-fill every image ticked on the Annotate page, each image then opens with its guesses
      already filled in. Nothing is submitted: annotators still check every field. Guesses below 60% are marked
      unsure. Retraining the model makes new guesses necessary; images that already have this model's guesses
      are skipped.
