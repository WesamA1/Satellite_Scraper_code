Data

Bringing annotated images in from elsewhere, and getting annotations out. Annotating itself is on the Annotate page.

Import

Adds a data folder's images (images/) and their answers (annotations.csv, or annotations/<annotator>.csv) to the database, so they join the scraped images in one pool. Files in the data folder are never moved. When an imported image is the same file as a scraped one, the imported copy is kept and takes over the scraped copy's license record; the scraped copy goes to quarantine. Rows the old tool's CSV wrote into the wrong columns are left out, so those images come up on the Annotate page to be labeled again. 



    

      Only an annotations CSV
      

        For an old-tool CSV (annotatedInfo.csv) whose images are already in the database, like scraped ones:
        rows are matched to images by file name and their answers kept as written, under the annotator name
        below. Rows that match no image, or whose values look like they're in the wrong column, are skipped
        and listed in a review file instead of guessed at.
      

      

        
        

          
          
        

        
        
      

      

    

  


  

    
Export annotations

    

      Writes every saved annotation to a CSV: one row per image and annotator, columns in the current
      attribute order (same layout as the old tool's annotatedInfo.csv, plus family and provenance columns at
      the end). Rebuilt from the database each time.
