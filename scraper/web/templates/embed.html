Embed

Turns every active image, plus every image in the training set (training/dataset.jsonl, if you've built one), into an embedding from a frozen pretrained image model. The attribute model trains on these. Images that are already embedded are skipped, so re-running only does new ones. The first run downloads the model from Hugging Face, which needs HF_TOKEN set on the API Keys page for DINOv3. To build a training set and train the model, use Train model.
