Import a data folder

Adds a data/ folder's images (images/) and their answers (annotations.csv, or annotations/<annotator>.csv) to the database, so they join the scraped images in one pool. Files in the data folder are never moved. When an imported image is the same file as a scraped one, the imported copy is kept and takes over the scraped copy's license record; the scraped copy goes to quarantine. Rows the old tool's CSV wrote into the wrong columns are left out, so those images come up here for annotating again. 


  


  

    Import from the old tool
    

      Brings in annotations made with the old desktop annotation tool (its annotatedInfo.csv),
      so those images count as done and don't come up again. Rows are matched to images by
      file name. Values are kept as written, under the annotator name below. Rows that match
      no image, or whose values look like they're in the wrong column (a known bug in the old
      tool's CSV), are skipped and listed in a review file instead of guessed at.
    

    

      
      

        
        
      

      
      
    

    

  


  

    Export annotations
    

      Writes every saved annotation to a CSV: one row per image and annotator, columns in
      the current attribute order (same layout as the old tool's annotatedInfo.csv, plus
      family and provenance columns at the end). Rebuilt from the database each time.
